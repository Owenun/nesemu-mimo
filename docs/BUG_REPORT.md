# nesemu 缺陷报告（Bug Report）

版本：0.1.x  
状态：阶段性收口；下列条目供本地审验与后续迭代。

---

## BR-01 口袋妖怪 Logo / 标题长时间假死

| 项 | 内容 |
|----|------|
| 严重度 | 高（曾被误判为 CPU 死锁） |
| 现象 | Logo 画面长期静止，PC 停在 \ |
| 根因 | \ 等手柄「新按下」$35；无输入则永远等待。NMI 与 INC  正常 |
| 处理 | headless utoplay 在 Logo 后脉冲 Start；桌面端手动按 Start/A 即可 |
| 状态 | **已关闭**（行为正确） |

---

## BR-02 标题底部绿色条带 / 图案表错误

| 项 | 内容 |
|----|------|
| 严重度 | 高 |
| 现象 | 标题下半为纯色横条；应有草地纹理 |
| 根因 | MMC3 A12 无低电平过滤，IRQ 扫描线计数过快，BG \/\ 切换行错误。tile \–\ 在 \ 为纯色，在 \ 才有纹理 |
| 处理 | A12 低电平 ≥8 点再计数；其后改为 **每可见行 dot 256 固定 1 次** clock_scanline_irq |
| 状态 | **已关闭**（标题纹理正常） |

---

## BR-03 战斗对话框 / 字乱码

| 项 | 内容 |
|----|------|
| 严重度 | 高 |
| 现象 | 战斗菜单与中文字缺失或错图块 |
| 根因 | 与 BR-02 同源（IRQ 分割 / CHR 表）；另与早期渲染路径缺陷有关 |
| 处理 | 随 BR-02 与 PPU 背景缓存修正一并解决 |
| 状态 | **已关闭**（用户确认战斗文字正常） |

## BR-05 垂直卷动时顶/底偶发串行（闪）

| 项 | 内容 |
|----|------|
| 严重度 | 中 |
| 现象 | 人物上下走、镜头卷动时，顶部数行偶现底部画面、底部数行偶现顶部画面；**停稳则正常**；部分帧好、部分帧差 |
| 分析 | 与 ine_Y 0–7 循环相关：ine_Y=0 时 240 行恰占满 30 tile 行；ine_Y≠0 时末 1–7 行 increment_y 在 NT 回绕。mir=0（vertical）时 NT Y 别名，对边内容出现在屏幕边缘 |
| 尝试过、已回退 | ① 强制 copy_vertical（渲染关闭时）→ 全屏花屏 ② MMC3 镜像 0/1 对调 → nametable 瓦解 ③ row29 钳位不回绕 → 卷动图块重复、观感更差 |
| 现状 | **保留硬件式回绕**；未再强行钳位。完整帧双缓冲已保留，排除呈现撕裂 |
| 状态 | **打开 / 阶段性接受** |

复现：口袋妖怪大地图（河边草地）上下走动；对比 ine_Y 奇偶步。

## BR-06 显示目标矩形小数像素导致边缘闪

| 项 | 内容 |
|----|------|
| 严重度 | 低 |
| 根因 | 4:3 缩放后 SDL_FRect 落在非整数像素，顶底扫描线重采样不稳 |
| 处理 | dst.x/y/w/h 向下取整到整像素；纹理 SDL_SCALEMODE_NEAREST |
| 状态 | **已关闭** |

## 流程教训

1. 改 PPU/Mapper 必须 **ROM 无头截图** 验证，不能只跑单元测试。  
2. 不要对调 MMC3/iNES 镜像语义。  
3. 不要在渲染关闭时无条件 	→v 复制（游戏用 \ 当 VRAM 指针）。  
4. 调试脚本与 uild/ 不入库。
